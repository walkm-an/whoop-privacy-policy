# Privacy Policy — Personal WHOOP Integration

This is a personal-use application created by the WHOOP account holder to sync their own data.

**Data collected:** Recovery, sleep, strain (physiological cycles), and workout data via the official WHOOP API, authorized by the user's own OAuth consent.

**How data is used:** Solely for the user's personal health tracking and analysis.

**Data sharing:** None. Data is never shared with, sold to, or processed by third parties.

**Storage:** OAuth tokens are stored securely in the user's private automation environment. No WHOOP data leaves the user's own systems except for API calls to WHOOP itself.
